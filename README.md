# Traffic Light Simulation — Racket

A functional programming exercise modeling a traffic light with red, yellow, and green states.

## Overview
The project defines traffic-light states, visual representations, and transition/timing logic.

## Concepts
- Structured data and state representation
- Functional decomposition
- Conditional transitions
- Graphics with DrRacket image teachpacks

## Run
Open `main.rkt` in DrRacket using the language and teachpack configuration indicated in the source file, then click **Run**.

## Files
- `main.rkt` — original coursework source with personal identifiers removed.

This is an educational simulation, not a real traffic control system. Runtime behavior has not been independently verified.
